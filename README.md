# Nukefy

Антивирус, антитроян и антимайнер для Windows. Монохромный минимализм: чёрный, тёмно-серый, серый, белый. Без эмодзи, без кричащих цветов. Electron + собственный движок детектирования.

## Что умеет

**Детектирование (вкладки «Вирусы», «Трояны», «Майнеры», «Риски»)**
- Локальная база сигнатур (`nukefy-db/signatures.json`): ascii / UTF-16 / hex-маски, логика any/all. Семейства: njRAT, DarkComet, NanoCore, Quasar/AsyncRAT, Remcos, Mimikatz, инфостилеры, стилеры кошельков, веб-шеллы, скрипт-дроперы, шифровальщики, майнеры (XMRig, ethminer, GPU-пулы, браузерные CoinHive-клоны), упаковщики.
- Эвристики: исполняемые файлы во временных папках и имена-маски (`svchost.exe` из Temp), PE с аномальной энтропией, скрипты «загрузка + скрытое выполнение + base64», майнер-конфиги со `stratum+tcp`.
- Облачная репутация по SHA-256: **MalwareBazaar** и **URLhaus** (abuse.ch) — бесплатно и без ключей; **VirusTotal v3** — по вашему бесплатному API-ключу (настройки → облачные базы).

**Проверка системы**
- Процессы: командные строки, маскарад системных имён, соединения с портами майнинг-пулов (3333/4444/5555/7777/8008/14444…).
- Автозапуск: реестр Run/RunOnce (HKCU/HKLM/WOW64), планировщик задач, папки Startup; поиск «сиротских» записей и записей, ведущих в Temp.
- hosts: обнаружение и восстановление файла, если заблокированы сайты антивирусов и обновлений (копия сохраняется).
- Резидентная защита: фоновый цикл проверок с настраиваемым интервалом и действием (уведомить / изолировать автоматически).

**Действия над угрозой**
- Вылечить (процесс — снять, автозапуск — удалить запись, hosts — восстановить, файл — обезвредить изоляцией),
- В карантин (с журналом и восстановлением байт-в-байт),
- Удалить безвозвратно,
- В исключения (по SHA-256/пути), Игнорировать, Открыть папку, Посмотреть на VirusTotal.

**Справка «?»**
- У каждой угрозы — значок «?» в круге: при наведении открывается карточка семейства: что делает, чем опасен, дата первого появления, откуда приходит, куда прописывается и рекомендация. База знаний — `nukefy-db/knowledge.json`.

**Анализ ссылок и страниц**
- Эвристики адреса: IP вместо домена, подозрительные зоны, тайпосквоттинг (levenshtein), имитация брендов, punycode, трюк с «@», открытые редиректы, HTTP.
- Возраст домена через RDAP, цепочка редиректов, ошибки TLS.
- Разбор страницы: браузерные майнеры, обфусцированный JS, скрытые iframe, авто-редиректы, формы открытым текстом, фингерпринтинг, перехват ввода; список трекеров слежки (GA/GTM, Meta Pixel, Метрика, Hotjar, Clarity и др.) и сторонних доменов.
- Репутация: URLhaus (URL и хост) бесплатно, VirusTotal — по ключу. Итог — оценка 0–100 и вердикт.

**Интерфейс**
- Полноэкранный запуск, плавная загрузочная анимация (отрисовка щита, поступенчатая инициализация), радар сканирования, вкладки, тосты, карантин, история проверок — всё в монохромной палитре с мягкими переходами.

## Релизы (EXE)

Готовые установщик и портативная версия публикуются в [Releases](../../releases) автоматически через GitHub Actions:
- `Nukefy-Setup-<версия>.exe` — установщик NSIS;
- `Nukefy-Portable-<версия>.exe` — один файл без установки.

Сборка вручную:

```bash
npm ci
npm test          # автономные тесты движка (15 проверок)
npm run dist      # Windows: NSIS + portable в папку release/
```

Запуск в режиме разработки: `npm start` (нужен бинарник Electron).
Превью интерфейса без Electron: `npm run preview` → http://localhost:4173 (демо-мост с имитацией движка).

## Структура

```
src/main/          главный процесс Electron, IPC
src/main/engine/   движок: сигнатуры, сканер, процессы, автозапуск, сеть,
                   карантин, хранилище угроз, анализ страниц, резидентная защита
src/preload/       контекстный мост (contextIsolation)
src/renderer/      интерфейс: разметка, стили, логика, демо-мост для превью
nukefy-db/         базы сигнатур и знаний (обновляются отдельными файлами)
test/              автономные тесты движка
.github/workflows/ сборка EXE и публикация релиза
```

## Честные ограничения

- **SmartScreen**: EXE не подписан код-подписью (платный сертификат), поэтому при первом запуске Windows может показать красный экран «Неизвестный издатель». Сверьте SHA-256 из `SHA256SUMS.txt` в релизе и нажмите «Выполнить в любом случае» (или ПКМ → Свойства → «Разблокировать»). Предупреждение исчезнет совсем после подписи сертификатом или по мере набора репутации загрузок.
- «Вылечить» для заражённого файла означает обезвреживание изоляцией: полиморфные тела файлов лечатся только сигнатурными инструментами уровня лаборатории; Nukefy честно помечает это в карточке действия.
- Облачные сервисы требуют интернета; без сети Nukefy полностью работоспособен на локальной базе и эвристиках.
- Продукт не заменяет коммерческий антивирус в корпоративной среде и предоставляется «как есть» (MIT).
